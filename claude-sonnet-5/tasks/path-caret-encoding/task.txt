Bring the url crate's path percent-encoding in line with the WHATWG URL Standard's path percent-encode set. Parsing a URL whose path contains a caret (U+005E `^`) must percent-encode it as `%5E`, as already happens for space, double quote, `<`, `>`, backtick, `{` and `}`. The path percent-encode set is defined as the query percent-encode set plus `?`, `` ` ``, `{`, `}` and `^`; keep the query, fragment, userinfo and special-path encode sets consistent with that definition so that userinfo and path segments still encode every code point they encode today. Web-platform test cases that currently fail only because of the caret must start passing, and the recorded list of expected failures must reflect that. Preserve the public API, add tests, and run the project's existing tests. Work only in this repository; do not use network access or retrieve an upstream solution.
